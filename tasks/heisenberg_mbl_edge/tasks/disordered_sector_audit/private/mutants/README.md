# Scientific mutation suite

`build_mutants.py` replaces one dormant author-only mutation selector in the
clean reference implementation and creates 12 complete programs.  Every case
parses, executes, and emits the full required result schema; rejection therefore
tests scientific discrimination rather than malformed-output handling.

The categories cover Hamiltonian coefficients/topology, nonunit exchange input
handling, reversed energy and
packet selection, entanglement and participation definitions, magnetization
moments, realization-first statistics, cluster SEM, and fabricated evidence.
